# UrMoments-inspired multi-page website

This is an original static multi-page website inspired by the service categories and structure of urmoments.ca.

## Pages
- `index.html` — home page
- `services.html` — photobooth, mirrorbooth, 360 booth, and add-ons
- `packages.html` — packages and promotions
- `backdrops.html` — backdrop options
- `gallery.html` — gallery placeholders
- `contact.html` — contact details and mailto inquiry form

## How to use
Open `index.html` in a browser. Edit the HTML text, pricing, phone numbers, email, and placeholder gallery tiles as needed.

## Notes
No images from the source site are copied. Placeholder SVG photo graphics were added in `assets/photos/`. To use real photos, replace those SVG files with your JPG/PNG/WebP photos and either keep the same filenames or update the `src` paths in the HTML files. The gallery, hero areas, services, and backdrop cards now use image tags.
